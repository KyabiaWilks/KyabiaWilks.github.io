📱 KyabiaHome 页面预览

查看所有页面的功能和预览方式

🎯 如何查看这些页面

方法一：使用 HBuilderX（推荐）

  1. 下载并安装 HBuilderX
  2. 打开 HBuilderX，文件 → 打开目录 → 选择 KyabiaHome 文件夹
  3. 点击"运行" → "运行到浏览器" → "Chrome"
  4. 在浏览器中可以看到完整的 uni-app 应用，包括底部导航
✅ 这是最佳方式，可以看到完整的页面功能和交互效果

方法二：查看源代码

  1. 在文件管理器中打开 pages/ 目录
  2. 每个页面文件夹包含一个 .uvue 文件
  3. 用文本编辑器打开这些文件查看代码结构
⚠️ 这种方式只能查看代码，无法看到实际效果

方法三：使用 uni-app CLI

  1. 安装 uni-app CLI：npm install -g @dcloudio/uni-cli
  2. 在项目目录运行：npm run dev:h5
  3. 在浏览器中查看完整应用
