## 🚀 快速开始

### 1. 进入项目目录
```bash
cd KyabiaHome
```

### 2. 使用HBuilderX打开项目
1. 打开HBuilderX
2. 文件 → 打开目录 → 选择KyabiaHome文件夹
3. 等待项目加载完成

### 3. 运行项目

#### H5端（网页版）
- 点击工具栏的"运行" → "运行到浏览器" → "Chrome"
- 或使用快捷键 `Ctrl+R`

#### 微信小程序
- 点击工具栏的"运行" → "运行到小程序模拟器" → "微信开发者工具"
- 确保已安装微信开发者工具

#### App端
- 点击工具栏的"运行" → "运行到手机或模拟器"
- 需要配置相应的开发环境

## 🚀 部署指南

### H5部署
1. 构建项目: `npm run build:h5`
2. 上传到静态网站托管服务
3. 配置CDN加速

### 小程序部署
1. 构建项目: `npm run build:mp-weixin`
2. 使用微信开发者工具上传
3. 配置小程序后台
4. 提交审核

### App部署
1. 构建项目: `npm run build:app`
2. 使用HBuilderX云打包
3. 配置应用签名
4. 上传到应用商店

## 🐛 常见问题

### Q: 项目无法运行？
A: 检查Node.js版本（需要16+），确保HBuilderX已正确安装

### Q: 图片显示不出来？
A: 检查图片路径，确保图片文件存在于 `static/images/` 目录

### Q: 小程序无法预览？
A: 确保已安装微信开发者工具，并正确配置AppID

### Q: 如何添加新页面？
A: 在 `pages/` 目录下创建新文件夹，在 `pages.json` 中添加路由配置
