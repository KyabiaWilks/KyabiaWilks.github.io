🚀 KyabiaHome 本地预览

基于 uni-app 的多端个人主页项目

📱 运行方式

方法一：使用 HBuilderX（推荐）

  1. 下载并安装 HBuilderX
  2. 打开 HBuilderX
  3. 文件 → 打开目录 → 选择 KyabiaHome 文件夹
  4. 点击工具栏的"运行" → "运行到浏览器" → "Chrome"
✅ 这是最推荐的方式，支持完整的 uni-app 功能

方法二：使用 uni-app CLI

  1. 安装 uni-app CLI：
npm install -g @dcloudio/uni-cli
  1. 在项目目录下运行：
npm install npm run dev:h5
⚠️ 需要先安装 uni-app 相关依赖

方法三：简单本地预览

  1. 安装一个简单的 HTTP 服务器：
npm install -g http-server
  1. 在项目目录下运行：
http-server -p 8080
  1. 打开浏览器访问：http://localhost:8080
⚠️ 这种方式只能预览静态文件，无法体验完整的 uni-app 功能
